# MoodDiary v1.1.0-alpha01 Released 🐤

> 记录每一天，你的内心助手

## ✨ 亮点 (Highlights)

* **📸 Tag 直调相册/相机**：春夏秋冬 Icon 随主题变化，拍照即记录情绪，让记录流程更加自然流畅。
* **🎉 国庆限定分享卡片**：新增国庆主题分享卡片，在记录当下的同时，也可以分享特别时刻。

## 🚀 v1.1.0-alpha01 更新概要

* **🐛 Bug 修复**：修复已知显示问题，提升整体稳定性。
* **🎨 全新 UI 与过渡动画**：全面优化视觉设计与交互体验。
* **📝 情绪 + 日记双记录模式**：新增 Mood + Diary 组合记录方式，让情绪与文字记录结合。
* **⚡️ 瞬间与记录双模块**：新增 Instant & Moment 双模块分类，让不同记录场景更加清晰。
* **🖼️ 历史记录时间线 Gallery**：新增月度 Gallery 视图，更直观地回顾过去的情绪与日记。
* **🎭 高度自定义能力**：支持自定义 Emoji、背景、Shape 等视觉元素。
* **🌐 多语言本地化完善**：新增并完善英语、韩语、日语、西班牙语支持，共支持 5 种语言。

## 🕵️ 隐藏内容 (Easter Eggs)

* **💧 Studio 预留 Liquid Glass 风格**：为未来版本探索更多视觉体验。

## ⚠️ 已知问题 (Known Issues)

> 作为 Alpha 测试版本（Alpha Build），当前版本仍可能存在部分未发现的问题。

* 可能存在未知 Bug，欢迎提交反馈。
* **CSV 导出功能尚未与日记系统完全打通**，计划在后续版本完善。
* 功能不断增加，首次使用可能需要一定适应时间——新手引导正在制作中。
