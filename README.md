# MoodDiary v1.1 Canary Build Released 🐤

> 记录每一天，你的内心助手

## ✨ 亮点 (Highlights)

- **📸 Tag 直调相册/相机**：春夏秋冬 icon 变化，拍照即记情绪，整个流程非常顺滑。
- **🎉 国庆限定分享卡片**：新增国庆主题分享卡片，记录当下的同时也适合分享。

## 🚀 v1.1 Canary 更新概要

- **🐛 修复**：修复了已知的显示问题。
- **🎨 全新 UI 与过渡动画**：视觉与交互体验全面升级。
- **📝 情绪 + 日记双记录**：新增 Mood + Diary 组合记录模式。
- **⚡️ 瞬间与记录双模块**：新增 Instant & Moment 双模块分类。
- **🖼️ 历史记录时间线月度 Gallery**：回顾过往情绪与日记更直观。
- **🎭 用户高度自定义**：支持自定义 emoji background shape。
- **🌐 完善多语言本地化**：新增并完善了英、韩、日、西语支持（共 5 种语言）。

## 🕵️ 隐藏点 (Easter Eggs)

- **💧 Studio 预留 Liquid Glass 风格**（敬请期待后续版本解锁）。
