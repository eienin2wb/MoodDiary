# 每日情绪账本 · MoodDiary

> 你的每一种情绪，都值得被认真对待。❤️

**MoodDiary** 是一款为“关照内心”而生的情绪记录工具。我们不需要复杂的长篇大论，只需简单记录，就能把每一天的心情留存下来。

---

## 核心功能

### 📝 心情记录与卡片生成
快速记录当日情绪，自动生成设计精美的情绪卡片，让记录本身成为一种享受。

### 🤖 AI 趋势分析入口
通过导出的结构化数据，你可以将其接入 AI 工具，让数据说话，智能分析你的情绪周期与变化规律。

---

## 技术要点

- **纯本地架构**：SQLite 存储，数据零上传，隐私安全从底层保障
- **卡片渲染**：基于 Canvas / 自定义 View 实现，支持导出 PNG，并适配 Instants
- **系统分享**：通过 `Intent.ACTION_SEND` 调用系统分享面板，不接入任何社交 SDK
- **CSV 导出**：基于 Storage Access Framework，方便后续对接 AI 分析工具
- **零追踪**：无埋点、无统计、无第三方 SDK

## 使用说明

### 记录心情
打开应用后，选择你当下的情绪状态，应用会自动生成一张精美的情绪卡片。你可以保存卡片或通过系统分享面板发送给朋友。

### 导出数据
在设置中开启 CSV 导出功能，将你的情绪记录导出为结构化数据文件。

### AI 分析
将导出的 CSV 数据接入你常用的 AI 工具（如 ChatGPT、Claude 等），即可获得个性化的情绪趋势分析。
